# Real-world sizes

Typical ranges in centimetres unless marked. Period pieces (medieval to 19th century) run lower and heavier than modern
ones where noted. When a size really matters, measure a reference: download a CC0 scan of a similar object
(`fetch_cc0.py search <word> --models`, then `fetch_cc0.py model <id>`) and run `check.py` on it for its size.

## People (for scale)
Adult height 160-180 (period populations 160-172); eye height 150-165; shoulder width 40-46; seated: seat 43-47 high,
elbow 65, eye 115-120; hand 18-19 long, palm 8-9 wide; door handle reach 90-105.
